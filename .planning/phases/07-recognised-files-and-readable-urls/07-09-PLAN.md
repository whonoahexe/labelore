<objective>
Give images and other binaries their pages (the UI half of DATA-08, D-08, D-09): an image opens on a
plain page that shows the picture through a hardened, images-only bytes route resolved through the
route table; every other binary, an oversized text file and an over-cap image open a static File

offers a raw view, a download or a new tab for a non-image binary, and no binary byte is read beyond
the classification sniff.

in the one way D-08 and D-09 allow, so a screenshot under ui-reviews/ is no longer a dead end.

FileDetailsPage, DocumentRoute's file-class branch, FigureFrame defaultFit and two CSS rules, the
