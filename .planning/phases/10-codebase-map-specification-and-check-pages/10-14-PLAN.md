## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| map document text to structured and the View DOM | A map author may write a secret beside a variable name |
| page to the clipboard | Run commands are document text the user may paste into a terminal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-24 | Information disclosure | liftIntegrations, IntegrationsPanel | high | mitigate | withholdValue stores names only; tests assert the planted value is absent from structured, the markup, titles and aria-labels |
| T-10-25 | Information disclosure | Source mode, plain sections, search index and snippets | medium | accept | outside this phase's scope by UI-SPEC: the raw document still holds any value written in it; recorded as a follow-up in 10-19-SUMMARY.md with the USER-SETUP case |
| T-10-26 | Tampering | Testing run-command copy rows | medium | mitigate | the copied text is exactly the visible, selectable command with control and bidirectional characters removed; the button never runs anything |
| T-10-SC | Tampering | npm installs | low | accept | this plan installs no packages |
</threat_model>
