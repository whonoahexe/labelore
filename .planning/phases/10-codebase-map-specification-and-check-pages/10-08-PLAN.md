## UI-SPEC deviations (recorded for the user's review)

- **C1 (fallback notice).** UI-SPEC section 6 promises "the existing warning chip and notice ('This file
  has a shape this page did not expect...')". That notice does not exist in src/; Phase 9 shipped a silent
  fall-through. This plan mirrors Phase 9: an unshapeable codebase file falls to the manifest's promoted
  sections with no new notice; the parse-warning chip shows only when the artifact itself carries
  warnings. Every later page plan in this phase follows the same rule.
- **C7 (bare /codebase).** No such address existed; this plan adds a redirect-only case (first mapped
  document, or the dashboard address for a map-only project).
- **C8 (one view kind).** One view kind codebase for the seven documents via viewKindOf, so the class
  prefix is view-codebase-* and the registry grows by one, not seven.
- **C6** (no Codebase header tab) stands as recorded in 10-01: in a normal project the page is reached
  from the drawer and search.

## Flagged assumptions

- "Mapped {date}" is the newest per-document date and the commit chip is that document's commit
  (RESEARCH A3); each panel keeps its own date in the panel list.
- One view kind rather than seven is rated costly to undo (registry, class prefix and tests would change)
  but stays behind viewKindOf, so a switch touches one function and the class names.
- The screenshot helper's ports 4190-4194 avoid the user's 4173-4174, Playwright's 4195-4199 and the
  e2e helpers' 5310-5329.
