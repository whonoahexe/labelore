## Contract split (read this first)

This contract locks what every page in the phase shares: tokens, tones, chips, squares, copy, states, the
generic-page fallback, accessibility and the made-up example rule. It also records, for the four pages whose
frame sketch is already validated, what the winning sketch fixed. It does **not** prescribe a frame for a
page whose sketch has not run yet (seed, thread, reports, forensics, onboarding): those are decided by their
own sketch inside the phase (D-16), and no page reuses the previous sketch's frame (user rule
`sketch-fresh-structure`). The "Must show" lists below are the content each page promises (they come from the
success criteria and CONTEXT); the sketch decides the order, weight and arrangement. If a sketch winner cannot
carry an item in a "Must show" list, the plan records the deviation; it does not silently drop the item.

Sketch words are not copy. Each sketch README lists "Sketch words, not UI-SPEC copy"; the Copywriting
Contract below is the final wording.

## Spacing Scale

Declared values (all multiples of 4), applied through existing tokens:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`--space-1`) | Icon and square to text gap, chip gap, meter cell gap |
| sm | 8px (`--space-2`) | Gap between a row's chips; gap between a label and its value; tile inner gap |
| md | 16px (`--space-4`) | Tile padding, row padding, gap inside a group, grid gap of the Indexes grid and the verdict board |
| lg | 24px (`--space-6`) | Gap between groups and sections; panel and sheet padding; branch gap in the workstream tree |
| xl | 32px (`--space-8`) | Gap between a main column and a side column; page top rhythm (through `page-stack` / `--space-fluid-*`) |
| 2xl | 48px | Not used by this phase |
| 3xl | 64px | Cover/head vertical padding only, through `--space-fluid-*` |

Exceptions:
- Rail, spine, connector, pin and ring geometry that a sketch locks (the pause path rail, the workstream tree
  connectors, the phase ring, the verdict-board column rules) is decoration, not layout spacing. It is written
  as `calc()` over `--space-*` tokens where an exact token exists, otherwise as one named custom property per
  view (the Phase 9 `--view-project-node-offset` precedent). No bare `px` or `rem` in a rule (design language:
  token-only spacing). Breakpoints are the sketch-locked ones: 48rem (Spikes board to stacks; sheet to full
  width), 52rem (pause path to two columns; workstream tree to an indented list), 56rem and 34rem (Indexes grid
  to two columns, then one). Under 42rem the five-tab top bar already wraps to two rows; a workstream-mode first
  screen shows fewer tabs, which must not break that rule.
- Copy buttons, the scope chip trigger, tile links, panel closers and the "Mark as read" toggle keep a hit area
  of at least 40px high under `@media (pointer: coarse)` (`min-height: var(--space-10)`); fine pointers keep the
  `xs` height (`var(--space-7)`, 28px). Both are existing tokens, not literals.
- A mono path, id or commit never sets the height of its row: it ends in an ellipsis on one line with the full
  value in `title`. The copyable command wraps (the `copy-command` rule). A free-text verdict and a next-action
  sentence wrap and are never truncated (see Layout rules).

### Tone mapping (document content only)

The four-square vocabulary (`status-square`, `data-tone`) is the shared one. A square is never the only carrier
of meaning: it always sits beside a word or has an `aria-label`. Chips are `status-chip` with `data-tone`.

| Meaning | Tone | Mark |
|---------|------|------|
| Finished, validated, done, present, resolved | `complete` | square filled `--primary` |
| Waiting on someone, partial, stopped here, behind, in progress | `in-flight` | square filled `--in-flight-fill` |
| Expected and absent, invalidated, blocking, failed | `missing` | square outlined 2px `--missing-fill` |
| Neutral, pending, not stated, advisory, dormant, left to do | `quiet` | square dashed `--muted-foreground` |

### Page-by-page tone use (default mapping; a sketch may refine within these four tones only)

- **Spikes (053 A, fixed).** VALIDATED `complete`, PARTIAL `in-flight`, INVALIDATED `missing`, PENDING `quiet`,
  a folder or spike with no verdict row: untoned, dashed ("neutral dashed"). The keyword picks the column and the
  tone; the free text after it is shown as written beside it. A verdict keyword the page does not know is shown
  verbatim as a `quiet` chip in the Pending column ("keyword groups, text is kept"). The "README says {verdict}"
  flag is a dashed `quiet` chip (a note that two records part ways, never a result, as the Phase 9 disagreement
  chip). "Wrapped up" is a `quiet` chip, never `complete`.
- **Pause (054 C, fixed).** Done tasks `complete`; the stopped-at task `in-flight`; tasks left `quiet` (dashed
  chips). A blocking human action, blocking constraint and blocking anti-pattern are `missing` (gate bars); a
  non-blocking action and an advisory anti-pattern are `quiet`. `HANDOFF.json ≠ .continue-here.md` blocks are
  dashed and `quiet` (two records part ways). "Work has moved on since" is a dashed `quiet` note beside the
  date, not a chip with a tone of its own. An unmarked gate is `missing`; a gate marked as read keeps its tone
  and adds a "Read" word (view state, never a pass).
- **Indexes (055 A, fixed).** "{n} commits behind" `in-flight`; "Last update failed" `missing`; "Last auto-update
  ok" `complete`; "running" `in-flight`; "Not built" tile `quiet`, hatched and dashed; "Not sent to this page"
  line `quiet`. Synthesis conflict chips: auto-resolved `quiet`, competing `in-flight`, unresolved `missing`.
  Stack, method, type and extraction-split chips are untoned. A stale graph with a failed update reads as two
  facts (old counts, failed refresh), never as one broken tile.
- **Workstream index (056 C, fixed).** Unfinished status `in-flight` with the status word verbatim (executing,
  verifying, planning); done phases `complete` fill in the ring; no roadmap `quiet`, dashed; the **Active** mark
  is an outlined label, not a tone, and carries no `--primary`; the active branch's heavy border is
  `--foreground`-weight, not accent. Completed workstreams in the closed bar are `complete` squares.
- **Seed.** Status: dormant `quiet`, active `in-flight`, triggered `in-flight`, any other value verbatim
  `quiet`. Scope Small / Medium / Large untoned chips; `unknown` or absent: `quiet` "Scope not stated". A
  missing `trigger_when`: `quiet` dashed "No surfacing condition".
- **Thread.** open `in-flight`, in_progress `in-flight`, resolved `complete`, an unrecognised status verbatim
  `quiet`. The word, not the tone, tells open from in progress.
- **Session report and milestone summary.** Headline numbers untoned. Blockers and open items `in-flight`
  (waiting on someone). Milestone requirement coverage: covered `complete`, not covered `quiet` (a coverage
  note, not a failure); a delivered phase `complete`.
- **Forensics.** Anomaly **confidence** (HIGH, MEDIUM, LOW) is an untoned `status-chip` with the word, sorted
  HIGH first: confidence in the finding has no good or bad polarity, and a tone would clash with the
  confidence mapping the Research page uses in the opposite direction. The artifact-completeness grid: present
  `complete`, absent `missing` (an expected artifact that did not appear; the word "Absent" sits beside the
  square). The hypothesis and recommended actions are untoned.
- **Onboarding.** The four-file pills: present `complete`, not found `quiet` dashed. Map readiness chip reuses
  the Phase 10 readings (Complete map `complete`, Fast map and Partial map `in-flight`).

## Layout and Interaction Contract

### 1. Shared rules (bind every page)

1. **Every page is a document page.** `ArtifactHeader` unmodified: breadcrumbs, copy-path button, View/Source
   toggle. Source mode shows the whole raw file (for JSON files it shows what Phase 12 Source mode shows today;
   see rule 8). Pages do not name their source file in prose except where a sketch-locked element is the path
   itself (an Indexes tile's path line, a pause file tag, "Files in {NNN-name}/").
2. **Nothing is dropped.** Anything the view does not claim stays reachable: a plain readable section below the
   designed part, a closed bar ("The rest of the handoff", the remaining spike sections), or an "In the source
   only" strip that links into Source mode at the heading (the Research / UI-SPEC precedent). A section that
   matches no known heading is shown, not hidden.
3. **Read-only, no state beyond the page.** The only client state is: open sheet or open tile (carried by the
   URL), disclosure open state, "Read more", the scope popover, the pause page's "Mark as read" toggle
   (`aria-pressed`, view state only, never written to any file and lost on reload), and any switch a per-type
   sketch adds. The one write-shaped affordance is **copy to clipboard** (command, path, line), which reads the
   page and writes nothing. **Labelore never runs a command and never opens, runs, renders or reads the content
   of a spike script, output file or snapshot** (success criterion 1): they are listed by name, kind and
   `stat` size only.
4. **Absence is silent** unless a specific absence is the point of the page ("Not wrapped up yet", "Not built",
   "No gates", "No roadmap yet"). Design language: `Nothing here yet.` is the only sanctioned generic absence
   string, and only when a visible absence surface is genuinely needed.
5. **Document text is shown verbatim** through the existing inline tokenizer: free-text verdicts, trigger
   sentences, next actions, requirement lists, context notes, thread steps and report outcomes are never
   re-worded. Computed words (ages, counts, "commits behind") are Labelore's own and are never presented as the
   file's.
6. **Keep disagreeing signals separate** (project rule). Two files, two fields or two counts that differ are
   shown side by side, each named, never merged and never "corrected": manifest verdict vs README verdict,
   HANDOFF.json vs `.continue-here.md` (task, status, next action wording), STATE `completed_phases` vs
   `completed_plans`, a seed's `status` vs nothing else. The disagreement block is a dashed, `quiet` frame with
   a text label; it is a fact about the files, not an error.
7. **Made-up examples look like any other document.** The UI has no "made up" chip and does not read the marker.
8. **Values that look like secrets.** HANDOFF.json `context_notes`, `decisions[]`, `human_actions_pending[]`,
   `uncommitted_files[]` and a seed's notes are free text and are shown as written (they are the author's
   words); the page adds no masking beyond Phase 6's `config.json` rule. If a field is a name beside a
   value-looking string (`KEY=…`), the pause and seed pages draw the name and the shared "Value not shown" mark,
   as User setup and Integrations do. The plan confirms whether such a value can reach search or the index and
   records it as an open item, not scope here (carry-over of Phase 10 open item 1).
9. **Tone is never colour alone**: every square or chip carries a word; every icon-only control carries
   `aria-label` and `title`.

### 2. Spikes page (VIEW-14; sketch 053 A, fixed)

Routes (Phase 7 scheme): `/{project}/spikes` (the manifest) opens the page with no sheet;
`/{project}/spikes/{NNN-name}` opens the page with that spike's sheet open; `/{project}/spikes/conventions` and

### 10. Accessibility

- **Headings.** One `h1` per page (`ArtifactHeader`). Panels, sheet title and sections are `h2`; groups are `h3`.
  Chips and squares are never headings. The sheet's title is its dialog `aria-labelledby`.
- **Board.** Each idea lane is a labelled group (`section` with the idea key as its `h3`); verdict columns are
  labelled lists inside it; each tile is one link whose accessible name reads "{id} {name}, {verdict} {free
  text}". The chip key under 48rem has the same words.
- **Sheet.** A Base UI Dialog: focus moves in on open, is trapped, Esc and the scrim close, focus returns to the
  tile that opened it; the page behind is inert while open. Deep-linking opens it on load.
- **Path (pause).** An ordered list; the stop carries `aria-current="step"`; "Mark as read" is a real
  `<button aria-pressed>` whose label stays "Mark as read" and whose pressed state is spoken; the toggle has no
  effect beyond the page and says so nowhere (it writes nothing). The disagreement block reads as text ("task:
  HANDOFF.json says 3, .continue-here.md says 4").
- **Indexes.** A tile that opens is a `<button aria-expanded aria-controls>`; Esc closes an open tile; the
  "Not built" tile is not focusable (`data-ghost`). Bars and the split bars have one accessible name each
  ("41,280 nodes, 78,100 edges"), cells `aria-hidden`.
- **Workstream tree.** A nested list with the root as its first item; each branch's name is the one link; the
  phase ring is `role="img"` with `aria-label` "4 of 8 phases done"; the plans bar is a `status-meter` with its
  exact label. The scope chip is a button with `aria-haspopup`, `aria-expanded` and an accessible name
  "Workstream: {name}"; its list is navigation (links with `aria-current="page"`), not a menu.
- **Copy buttons.** Real `<button>`s with a visible label and an `aria-label` naming what is copied; the toast
  is announced by the existing toast region. A command is selectable text outside the button.
- **Squares and meters.** Squares are `aria-hidden` when a word sits beside them; otherwise `role="img"` with an
  `aria-label`. A meter has one accessible name, its cells `aria-hidden`.
- **Live regions.** None (nothing updates on a timer).
- **Contrast.** Every new text colour is an existing token validated in both themes; `--muted-foreground` on
  `--card-veil` and on the hatched "Not built" and "no roadmap" grounds is the weakest pair and is checked in the
  screenshot review.
- **Narrow widths (390px).** The board becomes stacks, the pause path two columns, the Indexes grid one column,
  the tree an indented list; the sheet is full width; no horizontal page scroll; mono paths and commits
  end-ellipsise with the full value in `title`; the scope chip trigger is at least 40px tall.
- **`prefers-reduced-motion`.** Nothing animates; nothing to disable.

## Copywriting Contract

Quote marks are literal; `{...}` is filled at runtime. Document text (verdict free text, trigger sentences,
next actions, steps, outcomes, context notes) is shown verbatim and never re-worded. Button and chip copy is
sentence case (the `Button` component uppercases it). Verdict and status words that GSD writes in capitals
(VALIDATED, PARTIAL, INVALIDATED, PENDING; HIGH, MEDIUM, LOW) are shown as the page's chip words in sentence case
("Validated") on the board, and verbatim wherever they are quoted from the file ("README says PENDING").

| Element | Copy |
|---------|------|
| Primary CTA (phase) | "Copy command" — the onboarding page's recommended command (shared `copy-command` row). Every other affordance is a link, a disclosure, a close, a switch or "Mark as read" (view state). Labelore never runs the command. |
