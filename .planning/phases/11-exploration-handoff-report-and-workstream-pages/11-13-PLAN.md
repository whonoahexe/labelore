## Flagged assumptions

- RESEARCH A2: GRAPH_REPORT.md's Summary carries counts and God Nodes; when it does not, the scan tier runs.
- RESEARCH A3 (rated reversible, a constant): a transient read of up to 96 MiB is acceptable for the scan;
  larger files read "counts not read". If the user wants true chunked streaming, an optional readChunks port
  method is the next step.
- RESEARCH A5: built_at_commit is a top-level key; the scan finds it wherever it sits at the top level, so the
  head-sniff shortcut is not needed.
- The cache is keyed by path, size and snapshot read time rather than mtime, because a 'large' artifact carries
  mtimeMs 0 in the snapshot (registry.ts); each refresh reads again.
