<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| target project's config.json -> Labelore read layer | Secret strings enter memory here and must not pass further in full |
| Labelore server -> browser and search index | Every API response and index entry derives from the parsed artifact |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-09 | Information disclosure | JsonConfigHandler frontmatter and body | high | mitigate | maskConfig at parse; end-to-end assertions over presentation, artifact route and search |
| T-06-10 | Information disclosure | config.json that fails to parse | high | mitigate | redactSecretText on the raw body; malformed-file test with a planted key |
| T-06-11 | Information disclosure | search index and snippets, including fragment queries | high | mitigate | Index inherits the masked body; fragment-query assertion |
| T-06-12 | Tampering | on-disk config.json | medium | mitigate | Masking only in memory; test compares content and mtime before and after a load |
| T-06-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no packages |

Note: masking is redaction for display, not protection of the file on disk (ASVS V6 does not apply).
</threat_model>
