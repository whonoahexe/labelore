    Create `test/web/class-vocabulary.test.ts` in the repo's text-scan idiom (`node:fs`, regex, no AST, no DOM). Implement and export (for the positive control) these pure helpers inside the test file:

    - `parseVocabulary(markdown: string): { classes: Set<string>; tones: Set<string> }` — split the doc on lines starting with `## `; within each section collect every match of a line-anchored pattern `| \`token\` |` where token is `[a-z][a-z0-9-]*`; sections whose heading starts with `Tones` feed `tones`, every other section feeds `classes`.
    - `extractClassTokens(source: string): string[]` — from a `.tsx` source string, after blanking `//` line comments and `/* */` block comments with equal-length spaces: (a) every `className="…"` attribute value; (b) every `className={…}` expression, found by walking braces to the matching close, from which every single- or double-quoted string literal is collected and every template literal is split on `${…}` into static segments — a static segment that immediately precedes a `${` keeps a trailing marker so the caller knows it is a prefix; (c) every `className: '…'` / `className: "…"` object property. Split every collected string on whitespace; drop empties.
    - `extractToneTokens(source: string): string[]` — every `data-tone="…"` literal plus quoted literals inside `data-tone={…}` expressions.
    - `viewLocalPattern(prefixes: readonly string[]): RegExp` — `^view-(p1|p2|…)-[a-z0-9-]+$` with each prefix regex-escaped (kinds contain hyphens: `discussion-log`, `milestone-audit`, `review-fix`, `ui-spec`, `ui-review`).
    - `checkTokens(tokens, classes, viewLocal): string[]` — returns the offending tokens: a plain token passes when it is in `classes` or matches `viewLocal`; a prefix token (from a template segment) passes when at least one documented name starts with that prefix; everything else is an offender.

    The suite: (1) `it('every className literal in views, pages and components is documented or view-local')` — glob `src/web/views`, `src/web/pages`, `src/web/components` recursively for `.tsx`, skipping any path containing `/components/ui/`; for each file compute offenders as `${relativePath}: ${token}`; sort; `expect(offenders).toEqual([])`; also `expect(scannedFiles.length).toBeGreaterThan(20)` and log the count so an empty glob cannot pass vacuously.
