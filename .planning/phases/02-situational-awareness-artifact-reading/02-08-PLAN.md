Export an interface `RoadmapDeepLinkTarget` with three fields: `kind: 'phase' | 'milestone'`,
`phaseUrl: string | null`, `milestoneUrl: string`.

Export `resolveRoadmapDeepLink(pathname: string): RoadmapDeepLinkTarget | null`. It calls
`parsePresentationUrl` from `../../presentation/routes.ts`. On a non-ok result, or on any route kind
other than `'phase'` or `'milestone'`, return `null` — never throw. For `kind: 'phase'` return
`{ kind: 'phase', phaseUrl: buildPhaseUrl(route.phaseIdentity), milestoneUrl: buildMilestoneUrl(route.milestoneVersion) }`.
For `kind: 'milestone'` return `{ kind: 'milestone', phaseUrl: null, milestoneUrl: buildMilestoneUrl(route.milestoneVersion) }`.
Rebuilding through `buildPhaseUrl` rather than comparing raw path segments is deliberate: it is what
makes the comparison encoding-proof, because the rendered rows' `url` fields come from that same
builder, and it sidesteps `useParams()` percent-decoding the identity segment out of alignment with
`phaseKeyOf`'s output.

Export `milestoneContainsDeepLink(milestone: { url: string; phases: ReadonlyArray<{ url: string }> }, target: RoadmapDeepLinkTarget | null): boolean`
