Detector: pluralization (one project per run becomes several).
Primary noun: the project registry entry, keyed by its persisted slug, owning one ProjectRuntime.
Decision: promote. ProjectRuntime and the slug-keyed registry become the only way the served app
reaches a snapshot. createApp(source) is demoted to a thin, guard-free, test-only wrapper that
mounts the very same createProjectApi with one fixed runtime at /api, so the existing server tests
keep running without a second set of handlers.
Invariant tests (accepted, built in this plan and 08-06): (1) route-set equality, every project API
route is reachable under /api/projects/:slug; (2) per-slug isolation, every parameterless GET route
answers each project's own data; (3) 08-06 adds a source scan that startServer constructs the
registry app and never createApp.
</assumption_delta_decision>

research Pattern 4). The request guard (SEC-05, D-18, D-20) is its own plan, 08-03, and is
