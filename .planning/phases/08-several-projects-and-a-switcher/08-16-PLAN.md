<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser request body to the registry | target strings in POST /api/projects are attacker-influenced until the guard and the parser accept them |
| settings.json entries to the registry | saved targets and slugs become registry entries at startup |
| Labelore process to target folders | the only write must never reach a target |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-10 | Tampering | FileSettingsStore write path | high | mitigate | path fixed at construction and the two-importer gate (08-04); settings-inside refusal for any target containing the settings directory, on add and on a remembered entry; byte-identical target-tree test over add, open, refresh and forget |
| T-08-13 | Information disclosure | secrets in settings.json | medium | mitigate | parseRemoteTarget refuses passwords; only the canonical root or the parser's rawPath is stored; file mode 0600 and directory 0700 (08-04's store) |
| T-08-14 | Tampering / Elevation of privilege | POST /api/projects target | high | mitigate | 08-03's guard first, then parseRemoteTarget and resolveTargetPath exactly once (leading dash, host and user patterns, shell false); ssh is syntax-checked only and connects lazily with the existing timeout |
| T-08-SC | Tampering | npm installs | low | accept | this plan installs no packages |

Torn or concurrent writes (T-08-11), corrupt or hand-edited files (T-08-12) and hand-edited slugs
(T-08-15) are mitigated in 08-04's model and store, which this plan only calls.
