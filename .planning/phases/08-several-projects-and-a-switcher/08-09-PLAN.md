## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| one tab's actions to the shared query cache | a refresh in one project runs in the same QueryClient as every other project in the tab |
| slugs to links | the failed-load and not-found ways back are built from slugs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-35 | Information disclosure / Tampering | snapshot refresh across projects | medium | mitigate | the refresh posts only to the URL's slug and invalidates only projectKey(slug) and projectsKey; a behavioural test proves another project's cached entry stays valid |
| T-08-36 | Spoofing (open redirect) | 'Choose another project' and the not-found way back | low | mitigate | both are AppLink targets ('/' or projectRootPath(openSlug), which collapses an invalid slug to '/'); the override context that let a link point into a project the URL does not name is deleted |
| T-08-SC | Tampering | npm installs | low | accept | this plan installs no packages |
</threat_model>
