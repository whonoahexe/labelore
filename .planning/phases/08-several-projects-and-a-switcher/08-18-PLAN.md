<decision_record>
## TGT-08 at phone width: accepted (this plan decides it)

At 42rem and below the snapshot pill shows only its dot. The visible "Read {time}" text goes there,
as in the chosen sketch 039 A. Above 42rem nothing changes.

- Where the read time stays: the pill's `title` ("Snapshot read {date} — click to refresh"), the
  pill's accessible description (its `aria-describedby` names the label, which stays rendered), and
  the polite `sr-only` live region. The dot keeps the state visible: primary when read, muted while
  pending, pulsing while refreshing, destructive with a destructive border on error.
- Why: on a phone the header's first job is to say which project is open (core value). The user
  picked 039 A, which makes exactly this trade. TGT-08 (v1.0) still holds for assistive tech and on
  hover.
- Cost accepted: at 42rem and below, a sighted touch user cannot see the read age (a `title` does not
  show on touch) without widening the window.
- Alternatives rejected: the controls on their own row (reverts quick-260911-vqe, which put them back
  in row one, and departs from 039 A); the age in the trigger's meta line (UI-SPEC fixes the meta to
  milestone and status, and it would squeeze the name again); a shrinkable, ellipsised label (the
  controls sit in an `auto` grid track sized to max-content, so a shrinkable label frees no brand
  width; this is the debug's root cause 2).
- Reversibility: reversible. It is one rule in the 42rem block.

## Mechanism: visually hidden, not display: none

The gap's missing list names `.snapshot-label { display: none }`. The debug session did not account
for `test/web/refresh-contract.test.ts` "never suppresses any .snapshot- selector from the layout at
any width (CR-02)", which fails on any `display: none` inside a rule whose selector names a
`.snapshot-` class. This plan hides the label visually instead. It uses the declarations of the
repository's own `.sr-only` rule, the same pattern `.milestone-retro-button > span` uses on phones.
The layout is identical: the label leaves the flow and adds no width, so the pill collapses to its dot.
The CR-02 guard stays unedited and passing, and the description node stays rendered, so the pill's
accessible description does not depend on hidden-node referencing.

## Scope kept to the gap

Sketch 039 A's other 42rem rules are left out. Those are the nav icons hidden and nav link padding in
row two, and a search label the build does not have. They do not share the brand row and the UAT did
not raise them.
