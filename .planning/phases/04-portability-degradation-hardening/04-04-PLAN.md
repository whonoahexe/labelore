<objective>
Prove the dashboard works on projects it has never seen, and make absence read as absence.

This plan closes the three portability requirements Phase 4 exists for. TGT-03 says the dashboard
renders correctly regardless of phase count, milestone count or config toggles; TGT-05 says an
artifact type it does not recognize still appears in navigation and renders as plain markdown;
TGT-04 says a missing optional artifact or directory produces an honest empty state, never an error
page. Research ranked overfitting the parser to one reference project as the single
highest-severity risk in this project, and the only real defense is running the assembled app
adversarially against fixtures that are not that reference project.

Purpose: Phase 1 proved the snapshot for these fixtures. It did not prove the *dashboard* for them,
and a snapshot that parses is not a page that renders. This plan drives every route of the real
server against all three fixtures plus a deliberately stripped copy, and gives every absence one
quiet, honest presentation.
Output: one shared empty state, an adversarial portability suite, and the phase's closing human
verification.
</objective>
