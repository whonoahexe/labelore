<objective>
Build sketch 015's winner, **B: Square strip · pairs · gap register**, as the UAT page view. A UAT.md is a live test session (frontmatter, a Current Test overwritten each step, numbered tests with expected/result fields, a Summary of counts, Gaps with diagnosis); the view answers "where does testing stand" at a glance: status and timestamps up front, the current test with real attention, one square per test, every test's expected beside its result, and the gaps as a register that opens to its diagnosis.

Purpose: UAT is the next type in the per-type view loop (DISCUSSION-LOG, CONTEXT, RESEARCH, PATTERNS are done). Today it renders through the generic promoted-section view with a three-fact block.

Extractor — src/planning-repo/handlers/uat-session.ts.** `extractUatSession(rawBody: string): UatSession`, pure, non-throwing on any string; a port of gen-data.mjs's parse with the same discipline as pattern-map.ts (T-qk7-01): HTML comments removed and counted by a linear indexOf scan (not a whole-document regex), `##` and `###` splits via `splitWithPreamble` / `splitFenceAware`, every regex applied to one clipped line at a time, no nested unbounded quantifier. Export the types. Model:
- `fields(text)`: the sketch's "key: value" scanner — a key line is a lowercase key of 2-25 characters (letters and underscores, not http/https/e.g) followed by a colon at column 0; a `|` value starts a block scalar; unkeyed lines continue the previous field with two leading spaces removed; values are trimmed, one pair of surrounding double quotes removed, escaped quotes unescaped. Lines before the first key form `lead`. Each field carries `key`, `value` and `blocks` (parseBlocks of the value).
- `current`: from `## Current Test` (or `## Resolution` when no current was found yet) when its fields include `name` → `{ number, name, expected, expectedBlocks, awaiting, fromSection }`; otherwise `currentLine` = the section's first non-empty text with surrounding square brackets removed. A `## Result` section also sets `currentLine` (first line) when none is set, and is kept as an extra.
- `tests`: each `###` of `## Tests`; title "N. name" gives number and name (else running index and the whole title); `result` normalised as in gen-data (contains pending → pending; starts pass/passed/closed → pass; starts issue or contains fail → issue; starts skip → skipped; starts block → blocked; else other) plus `resultRaw` (unquoted, brackets kept); `fields` in source order; `lead`.
- `summary`: the `## Summary` fields as a key → value map.
- `gaps`: the first `##` whose heading starts with "Gaps". When any line starts `- key:` → mode 'items': each item a record of string values, with `artifacts` and `missing` as arrays (a four-space `- path:` line opens `{path, issue}`, a six-space `issue:` line fills the last one, a plain four-space `- x` pushes a string; `[]` means empty), continuation lines appended to the current string key. - `extras`: every other `##` in document order as `{heading, blocks}` (Current Test, Resolution-used-as-current, Tests, Summary and the Gaps section are claimed).
