<planner_notes>
Discretion decisions. Record each in plain language in the SUMMARY:
- **Explore notes keep the Lifted | As written toggle.** Variant A's own code gave explore notes no toggle. The README lists the toggle as common to all three variants, and dropping the rendered document would leave Source as the only way to read the full note. Lifted shows the Section by section ledger. As written shows the document as the app renders it, with its leading H1 dropped.
- **Read + opens the section as the app renders it.** The composer pairs each lifted section with a depth-2 entry of `input.headings`. It pairs by order when the counts match, and otherwise by heading text with `**`, backticks and `[[`/`]]` removed. An unpaired section has no Read +. The view slices that section out of the sanitized document HTML with the pure `sectionHtml(html, id)`: from just after the matching `<h2 …id="<id>"…>…</h2>` to the next `<h2` or the end, and '' when it is not found. The slice goes through the page's `renderHtml`, so tables, code and links render as on any document page.
- **Titles.** A quick note's h1 is the file-name title, built by the handler with the sketch's `slugTitle` rule: the last path segment, without `.md` and without a leading `YYYY-MM-DD-`, with hyphens as spaces and the first letter capitalised. The gist (the first sentence, with "Label: " kept for a labelled lead) is a large paragraph in the main column, not a heading. An explore note's h1 is the frontmatter title, else the first H1, else the artifact title.
- **Where it went.** The stage comes from the first Became todo: done reads "Shipped", pending or unfiled reads "Todo open". With no Became todo, a `promoted: true` note is "Untraced" and any other note is "Still a note". The sentences are:
  - "Became a todo and shipped <d>." (or "Became a todo and shipped." when no date is found);
  - "Became a todo, still open.";
  - "Promoted, but no todo carries it.";
  - "Still a note, <age> on.".
  An explore note's chip reads "N sections" ("1 section"), on stage open when any todo points here, else note. The explore big number's bar takes the untraced colour when an open question or block is flagged, else done (the sketch's rule).
- **Stats.** The Promoted row appears only when `promoted` is a boolean ("No" takes missing). The Todo row appears only with a Became todo: its status label takes its status tone, so Done is complete and Pending in-flight. The Note → shipped row appears only with a shipped date. Age compares the note's written wall time (date and HH:MM read literally) with `now`'s local wall time, so tests pass `new Date(2026, 9, 23, 12, 0)` and hold under TZ=Asia/Kolkata and UTC. Explore notes have no Age row.
