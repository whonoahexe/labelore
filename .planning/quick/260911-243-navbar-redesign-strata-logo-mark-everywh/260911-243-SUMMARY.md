# Quick 260911-243: Navbar Redesign (Strata Mark, Brand Lockup, Segmented Tabs, ⌘K Search Dialog, Status Pill) Summary

**Header rebuilt around a shared LabeloreMark SVG component (D-01 "Strata" path), a brand/meta lockup driven by pure `projectDisplayName`/`formatProjectMeta` helpers, underline-only segmented tabs, a merged snapshot-status pill absorbing the former refresh control, and search moved into a full-screen @base-ui/react Dialog opened by ⌘K/Ctrl+K.**

## Accomplishments

- Replaced the lucide `Tag` brand glyph everywhere with one shared `LabeloreMark` component (`src/web/components/labelore-mark.tsx`), consumed by both the header tile and a redrawn `public/favicon.svg` on the primary/primary-foreground oklch tile — confirmed present in the built `dist/favicon.svg` and the main JS bundle.
- Added `src/presentation/shell-header.ts`, a pure (no-DOM, no-React) helper module holding `projectDisplayName`, `formatProjectMeta`, `formatReadAt`, `formatRelativeReadAt`, `isSearchShortcut`, `isEditableTarget`, and `shortcutHintFor` — real-imported by tests and consumed by three separate `.tsx` components.
- Rebuilt the header brand block into a `tile / LABELORE / project name / meta line` lockup, with the meta line built from `presentation.data.state` ("v3.0 · Phase 1/2 · 67%" verified live against `fixtures/dense`), graceful omission of missing parts, a rootPath-basename fallback for the project name, and the full rootPath as the accessible title/tooltip.
- Restyled the three existing tabs (Dashboard/Roadmap/Traceability — no fourth tab added, per D-02) as a tighter segmented bar with a `--primary` underline (`box-shadow: inset 0 -2px var(--primary)`) and no filled active background.
- Merged the former `RefreshControl` into a new `SnapshotStatus` pill (`src/web/components/snapshot-status.tsx`): a dot plus "Read {relative}" inside a `<time>` with the exact time in the tooltip, re-rendered every 30s, keeping the unfiltered `invalidateQueries()`, scroll-to-top, fixed toast copy, `data-snapshot-read-at`, and `aria-label="Refresh the project snapshot"` contract byte-for-byte. `refresh-control.tsx` deleted; `refresh-contract.test.ts` retargeted onto the new component and still passes in full, including the six structural keyboard-behaviour pins.
- Rewrote `search-field.tsx` as `SearchDialog`: an icon trigger with a platform-aware ⌘K/Ctrl K hint, opening a centred `@base-ui/react/dialog` over a full-screen scrim (new `--overlay-scrim` token, distinct light/dark values) wrapping an inline `Combobox`. Every Phase-3 behaviour is unchanged — `DEBOUNCE_MS`, `DROPDOWN_LIMIT`, the AbortSignal-driven `queryFn`, the building/error/empty states, keyboard highlight, Enter-to-row-or-`/search?q=`, and "See all N results" — plus a global keydown listener that respects other editable fields and cleans up on unmount.
- Added new named tokens per NAV-06: `--overlay-scrim` (root + `.dark`, different values) and non-`--space`-prefixed dialog geometry tokens (`--dialog-offset-top`, `--dialog-max-width`, `--dialog-results-max-height`). `token-guard.test.ts` passes unchanged; no `.snapshot-` selector is ever `display: none` at any width.
