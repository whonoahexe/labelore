# Phase quick-261003-528 Plan 01: UI-REVIEW scorecard (sketch 018 B) Summary

A UI-REVIEW.md now renders as sketch 018's winner: a hexagon radar of the six pillar scores beside the verdict, fix pins and method chips, a pillar tab bar, and an inspector that puts each pillar's issues and fixes before its passes, with the back matter folded at the end. It plugs in through the same seam as UAT (handler -> `structured.uiReview` -> manifest hook -> artifact page) and degrades to today's promoted view when the review does not compose or carries a parse warning.

## What was built

- `extractUiReview` (server): tolerant, fence-aware, line-bounded projection. Pillar table and overall, per-pillar findings (groups of pass / flag / fail / note items with sub-lists and code), verdict line, Contract / Audit Method notes, fixes with pillar links (the pillar's own "See Priority Fix N", else pillar names and keywords in the title, then the text), history, back sections with sub-parts, and a Files Audited tree. File refs are found token by token (no global pattern over a line); "Priority Fix" via indexOf; a 1 MB body with a 200k-character line extracts well inside 250 ms.
- `UiReviewHandler` (kind `ui-review`, token UI-REVIEW) adds `structured.uiReview` plus `pathPhase` from `ref.phaseIdentity`, inside try/catch.
- `composeUiReview` (pure) and the exported tone maps, `radarGeometry`, `classifyShots`, `statusChip`.
- `UiReviewIntroMeta` and `UiReviewView` (radar, side column, tabs, inspector, unlinked-fix block, back matter, source-only strip), `stepPillar` for the keyboard handler.
- One delimited CSS block `quick-261003-528` right after the wfs block.
- Tests: extractor, handler guard, composer + static markup, real-corpus guard, source-text contract.

## Planner-note decisions, as built

- Phase number strips leading zeros ("Phase 6"); precedence frontmatter -> `pathPhase.number` -> H1. Title slug: frontmatter `slug` -> `pathPhase.slug`. (studio-portal 03 has no frontmatter and reads its title from the path.)
- Header chrome is the shared `ArtifactHeader` from one early return after the `crumbs` array (View mode, `warningTone === null` only); `hideCrumbs`, null lead, no metadata disclosure. Facts row shares the meta row with copy-path and View/Source.
- Baseline chip is a `Link` to the sibling `ui-spec` artifact's server URL when one exists, else a quiet chip; raw Screenshots and Baseline text ride on the chips' `title`.
- Group leads and stray pillar lines kept (a `**Label:** sentence` heading opens a group titled Label and its sentence is the first item; lines ahead of the first label form an untitled group). Contract / Audit Method lines stay out of the inspector and are named in the source-only strip.
- Found cards show sub-lists and code (lb05's Color code block renders). Fix cards: Why = User impact else context (clamped to three lines with more / less over 240 characters), Do = Fix, file refs are copy chips; unlinked fixes get a "Not tied to a pillar" block (no corpus doc triggers it). No-fixes: full marks -> a complete-tone "Nothing to fix." box with the author's note; points lost with no fixes -> a quiet line (no corpus doc triggers it).
- Other header facts (Interaction captures, This audit) render as quiet lines under the chips.
- Files Audited groups by directory inside each `###` / caption group and keeps non-file lines as plain rows. Back sections stay in document order; `###` sub-headings render as a bold line.
- Source-only entries are computed per doc. Arrow keys: a document keydown listener, acting only on the body or inside the view, no modifier, never in an editable element; removed on unmount.
- 62rem / 42rem media queries stand in for the sketch's container queries. The manifest lead stays verbatim and is hidden behind the cover in View mode.

## Changes the side-by-side forced (old -> new)

- Back-matter `<summary>`: plain sans -> mono uppercase muted key style (the sketch's link-button look).
- Earlier-review history bars: `--muted` (near-invisible in light) -> `--border`. A first attempt with `--muted-foreground` was too heavy next to the sketch's pale bars. The plan named `--muted`; this is a recorded deviation (token only, no new hue).
- Radar "fix N" labels: lower case -> uppercase with `--ls-wide`, as the sketch's label text.

## Winner deviations left in place

- Controls (copy-path, View/Source) sit on the facts row below the title, not on the eyebrow row (shared `ArtifactHeader`, same placement as the UAT and UI-SPEC pages).
