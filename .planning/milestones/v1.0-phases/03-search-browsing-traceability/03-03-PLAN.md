<objective>
Give the app a persistent left sidebar that mirrors `.planning/` exactly as it sits on disk.

Purpose: Search answers "where is this token"; the tree answers "what is actually here". It is the
escape hatch that stays useful precisely where the domain model cannot interpret a directory, which
means its value is entirely in being literal — including about the files the tool did not understand
and the directories it deliberately skipped.
Output: A tree view model over the assembled snapshot, a persistent sidebar consuming the dormant
--sidebar tokens, and a shell restructured from header-over-content into header-over-sidebar-plus-content.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| snapshot artifact paths → tree node labels | Corpus-derived filenames and directory names are placed into the DOM |
| exclusion ledger → stub node text | Discovery-recorded reason strings are rendered to the user |
| tree node → browser navigation | A node's destination determines where a click lands |

## STRIDE Threat Register (OWASP ASVS L1; unresolved high severity blocks completion)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03-01 | Tampering | tree node label rendering | high | mitigate | Filenames, directory names and exclusion reasons render as escaped React text nodes; React's raw-HTML injection prop is absent from the new component, asserted by source grep. |
| T-03-03-02 | Tampering | node destinations | high | mitigate | Every url comes from a route builder or from the DTO key the builder already produced; a source grep confirms no href is assembled by concatenation, so a crafted filename cannot become a crafted route. |
| T-03-03-03 | Tampering | `.planning/` target directory | high | mitigate | The tree projection and the sidebar component import neither `node:fs` nor `node:path` and never call discover(); the projection reads the assembled snapshot only, asserted by source grep. |
| T-03-03-04 | Information disclosure | exclusion stub reasons | low | accept | Reasons are discovery's own fixed strings describing the tool's own skip rules; they disclose nothing about the user's content. |
| T-03-03-05 | Denial of service | deeply nested tree rendering | low | mitigate | Discovery already terminates the walk at its maximum depth and records the termination as an exclusion, so the projection's input depth is bounded before it reaches the component. |
</threat_model>
