Create `src/web/pages/scroll-settle.ts` exporting a `ScrollSettleHost` interface with four members —
`measure(): number | null` returning a numeric layout signature for the target, `scroll(): void`,
`schedule(callback: () => void): number`, and `cancel(handle: number): void` — and a function
`scrollWhenSettled(host: ScrollSettleHost, options?: { maxFrames?: number; stableFrames?: number }):
() => void` that returns a disposer.

The loop: measure; if the measurement is null, stop. Scroll. Schedule the next frame. On each
subsequent frame, measure again; when the new signature equals the previous one, increment a
stability counter, otherwise reset it to zero and scroll again. Stop when the stability counter
reaches `stableFrames` (default `2`) or when the total frame count reaches `maxFrames` (default
`30`, roughly half a second at 60Hz — bounded so a page with a perpetually animating element cannot
spin forever). The module imports nothing from React and references no DOM global, so vitest runs it
against a fake host with no jsdom.
