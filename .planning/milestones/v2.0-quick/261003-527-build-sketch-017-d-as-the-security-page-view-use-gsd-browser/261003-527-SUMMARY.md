## Discretion decisions, as built

- Eyebrow strips leading zeros ("03" -> "Phase 3"); title is the humanized slug.
- Gauge number = `threats_open` when whole, else the open-blocking row count; verdict is "blocking sign-off" / "N below <level>, non-blocking" / "nothing blocking", then "N of M closed" once (fixes the sketch's duplicate line).
- Square status is the doc's own Status cell (below/non-blocking -> open-low, starts with open -> open, accepted/closed/verified/mitigated/resolved -> closed, else quiet "—"). The fixture's open medium threat is therefore blocking, matching its `threats_open: 1`.
- Blocks at: frontmatter `block_on`, then the register legend (`block_on <level>`, "at or above <level>", "below <level> threshold"), else high.
- Threat title = component, else group, else category, else id; the panel skips the category line when the title came from it.
- Risk <-> threat matching uses any `T-…` token shared between the risk's ref cell and a row's id cell (grouped rows, comma lists); an unmatched ref renders as plain text.
- Cell squares order open blocking, open non-blocking, closed; no square is picked on load.
- Unrated severity gets its own row; a register without a table renders its prose in place of the board.
- Boundary descriptions: a "why" disclosure under each row plus the row `title`.
- "In the source only" strip added (Frontmatter; Register legend when the register has one and its heading resolves).
- Summary omits the template blockquote; the long rationale (> 320 chars) clamps to three lines with more / less; the audit switch scrolls to the trail; in View mode the rail replaces the header, breadcrumb row and metadata disclosure; a parse warning shows as its chip in the rail.
- Tokens instead of the sketch's mix recipes (closed square `--primary`, hatching `--figure-grid-line`, into nodes and stamp `--figure-node-border`, alarm border `--missing-border`, pips `--muted-foreground` / `--foreground`).
