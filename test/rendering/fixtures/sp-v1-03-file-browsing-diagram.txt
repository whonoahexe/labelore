│                                                                        │
│  GET /api/browse/{tier}/{path}                                       │
│    ├─ VerifiedIdentity extractor (existing)                          │
│    ├─ TierId::from_str(tier) — closed enum, reject unknown           │
│    ├─ tiers::scope::resolve(tier_root_dir, path)  ◄── THE boundary   │
│    │     Local:  cap_std::fs::Dir::open_ambient_dir(mount_path)      │
│    │             → dir.read_dir(relative_path)                       │
│    │             bridged onto a dedicated std::thread (D-16),        │
│    │             awaited via a channel with a wall-clock deadline    │
│    │     Cloud:  bounded_proc::run_bounded(rclone lsjson ...)        │
│    │             bridged the SAME way — never called inline in the   │
│    │             async handler (it is a blocking, sleep-polling fn)  │

│    ├─ VerifiedIdentity extractor                                     │

│    └─ tickets.mint(..., TicketPurpose::Download { tier, path })      │

│  GET /dl/{ticket}                                                     │
